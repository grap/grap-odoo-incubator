This module facilitates the link between customer and inventory
management : it adds a function that create the right Return Stock
Picking according to the Refund method you use :

- With classic Credit Note, create a Return Stock Picking with the new
  quantities
- With the 'modify' flow, create a Return Stock Picking with quantity
  differentials.
