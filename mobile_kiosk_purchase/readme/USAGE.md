- Click on "Mobile Apps" Menu.
- Launch the "Purchase" application.

![application_launch](../static/description/application_launch.png)

- The next page proposes to the user to select a supplier.

![purchase_order_first_page](../static/description/purchase_order_first_page.png)

- Click on Select a supplier and click then on the supplier you want.

![supplier_select](../static/description/supplier_select.png)

- The next page allows you to choose a product.

![product_scan_or_select](../static/description/product_scan_or_select.png)

If you use a mobile with a barcode scanner, you can scan a barcode, to
select the product.

Otherwise, you can manually select a product, if it doesn't have a
barcode set.

![product_select](../static/description/product_select.png)

- The next page allows you to set a quantity. Tip a quantity, then click
  on the button "Add quantity"

![product_set_quantity](../static/description/product_set_quantity.png)

Note that quantity will be changed, if it doesn't match with product
configuration. (Minimum Quantity / Multiplier Quantity / etc.)

![quantity_rounded](../static/description/quantity_rounded.png)
