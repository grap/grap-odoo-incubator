This module improves the Odoo HR Expense modules.

By default, it is not very easy for the end user, if hr amount are vat
excl, or vat incl.

This module makes the HR Expense module more explicit. It displays:
"Total Vat Excl.", "VAT Amount" and "Total Vat Incl." fields.

It hides Taxes fields, to prevent user to change taxes.
